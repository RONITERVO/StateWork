# API quick reference

This page covers the calls the kit and recipes use, with argument order, units and return conventions. It was read from the SOLIDWORKS 2025 (33.x) interop. For anything else, `scripts/api-lookup.ps1` prints exact signatures (parameter names, ref/out, return type), properties and enum values from the installed interop in any shell: `-Type IModelDocExtension -Member SaveAs3`, `-Enum swMateType_e`, `-Search Rollback`. The official help page (`ApiHelpPaths` in the session probe, or help.solidworks.com) adds remarks and examples. C# signatures below omit the interface prefix: `ISldWorks` is the application, `IModelDoc2` a document.

## Conventions that apply everywhere

- **Units.** Lengths are metres and angles radians in every call, whatever the document displays. SwKit converts from millimetres at its boundary.
- **Failure without an exception.** Most calls return `null`/`false` or set an out/ref error instead of throwing. Check every return before using it. After creating a feature, call `IFeature.GetErrorCode2(out bool isWarning)`; a code of 0 means OK, and `isWarning` is meaningful only when the code is nonzero.
- **Bitmasks.** Errors and warnings from open/save are bitmasks with different enums for load and save. Decode them; don't compare to one value.
- **Model frame.** In a part, Front = XY (normal +Z), Top = XZ (normal +Y), Right = YZ (normal +X). Default planes come first in the feature tree as `RefPlane` features, in that order. Their display names are localised.
- **Selection state.** Most creation calls act on the current selection. Clear it first (`ClearSelection2(true)`) and after.
- **Modal prompts block calls.** With the user option `swInputDimValOnCreate` on, adding a dimension opens the Modify box and the call waits for a person. Toggle it off around the call and restore it.
- **Stale handles.** Feature, face, edge and body handles can raise `RPC_E_DISCONNECTED` after a new document's first `SaveAs` or an export. Look them up again.

- An equation-driven dimension reports `IDimension.DrivenState == swDimensionDriven`. Check for reference dimensions when you create them, before attaching equations; do not treat "driven" on an equation target as a fault.
- Feature, face, edge and body handles can disconnect (`RPC_E_DISCONNECTED`) after a new document's first save, an export, a configuration switch or a rollback. Look them up again afterwards.

## Documents

| Task          | Call                                                                                                            | Notes                                                                                                                                                                                                       |
| ------------- | --------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Template      | `GetUserPreferenceStringValue(swDefaultTemplatePart / ...Assembly / ...Drawing)`                                | Fall back to `*.prtdot` / `*.asmdot` / `*.drwdot` in `swFileLocationsDocumentTemplates` (`;`-separated). Use absolute paths.                                                                                |
| New           | `NewDocument(template, 0, 0, 0)`                                                                                | Null on failure. Set units: `Extension.SetUserPreferenceInteger(swUnitSystem, 0, swUnitSystem_MMGS)`.                                                                                                       |
| Open silently | `spec = GetOpenDocSpec(path); spec.Silent = true; spec.ConfigurationName = ...; OpenDoc7(spec)`                 | Null on failure; read `spec.Error` / `spec.Warning`.                                                                                                                                                        |
| Already open? | `GetOpenDocumentByName(path)`                                                                                   | Only one document per file name can be open; a same-named copy elsewhere is not loaded while the first is open.                                                                                             |
| Activate      | `ActivateDoc3(title, false, swDontRebuildActiveDoc, ref errors)`                                                | Sketching needs the document to have an active window.                                                                                                                                                      |
| Save / export | `Extension.SaveAs3(path, swSaveAsCurrentVersion, swSaveAsOptions_Silent, null, null, ref errors, ref warnings)` | Returns bool. The extension picks the format (`.step`, `.stl`, `.pdf` ...); a non-native export leaves the document's own path unchanged. `swSaveAsOptions_SaveReferenced` (4) also saves dirty references. |
| Dirty?        | `GetSaveFlag()`                                                                                                 | Separate from `Extension.NeedsRebuild2` and configuration dirty flags.                                                                                                                                      |
| Close         | `CloseDoc(titleOrPath)`                                                                                         | Check `GetSaveFlag()` first, and never close a document with unsaved changes the job did not make.                                                                                                          |

## Selection

| Selecting                        | Call                                                                                                           |
| -------------------------------- | -------------------------------------------------------------------------------------------------------------- |
| Feature (plane, sketch, feature) | `IFeature.Select2(append, mark)`                                                                               |
| Face / edge / vertex             | `IEntity.Select4(append, selectData)`. For a mark: `data = SelectionManager.CreateSelectData(); data.Mark = n` |
| Sketch segment / point           | `ISketchSegment.Select4(append, null)`, `ISketchPoint.Select4(append, null)`                                   |
| Component                        | `IComponent2.Select4(append, null, false)`                                                                     |
| Sketch origin                    | `Extension.SelectByID2("Point1@Origin", "EXTSKETCHPOINT", 0, 0, 0, append, 0, null, 0)`                        |

Selection marks used by features:

| Operation          | Marks                                                   |
| ------------------ | ------------------------------------------------------- |
| Linear pattern     | direction (plane or straight edge) 1, seed features 4   |
| Fill pattern       | seed feature 4, direction edge 1, boundary sketch 16384 |
| Mates (`AddMate5`) | both entities 1                                         |

## Sketches

| Task                      | Call                                                                                                                                           | Notes                                                                                                                                                                                                                                                                                             |
| ------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Open / close              | select plane or face, `SketchManager.InsertSketch(true)`                                                                                       | The same call closes the open sketch. `GetActiveSketch2()` is the open sketch; cast it to `IFeature` to name it.                                                                                                                                                                                  |
| Model to sketch           | `ISketch.ModelToSketchTransform` (MathTransform); `MathUtil.CreatePoint(xyz).MultiplyTransform(t)`                                             | Sketch x/y differ per plane: Front is (x, y); Top is (x, -z); a face sketch has its own axes.                                                                                                                                                                                                     |
| Exact creation            | `SketchManager.AddToDB = true`, `DisplayWhenAdded = false`                                                                                     | Restore both in `finally` (DisplayWhenAdded first). `CreateSketchSlot` also needs `swSketchInference` and `swSketchAutomaticRelations` user toggles off.                                                                                                                                          |
| Line / rectangle / circle | `CreateLine(x1, y1, 0, x2, y2, 0)`, `CreateCornerRectangle(...)` (4 lines), `CreateCircleByRadius(cx, cy, 0, r)`                               | Sketch coordinates in metres.                                                                                                                                                                                                                                                                     |
| Slot                      | `CreateSketchSlot(swSketchSlotCreationType_line, swSketchSlotLengthType_CenterCenter, width, x1, y1, 0, x2, y2, 0, 0, 0, 0, 1, addDimensions)` | The arc centres are the slot ends; with `addDimensions` you get width and length.                                                                                                                                                                                                                 |
| Dimension                 | select entities, then `AddDimension2(x, y, 0)` / `AddHorizontalDimension2` / `AddVerticalDimension2`                                           | Returns DisplayDimension or null (zero distance, bad selection). `GetDimension2(0)` gives the Dimension: `FullName` (`D1@Sketch1@Part1.Part`), `SystemValue` (m), `DrivenState` (1 driven, 2 driving).                                                                                            |
| Relation                  | select entities, `SketchAddConstraints(name)`                                                                                                  | Common names: `sgHORIZONTAL2D`, `sgVERTICAL2D`, `sgCOINCIDENT`, `sgMERGEPOINTS`, `sgHORIZONTALPOINTS2D`, `sgVERTICALPOINTS2D`, `sgSAMELENGTH`, `sgPARALLEL`, `sgPERPENDICULAR`, `sgTANGENT`, `sgCONCENTRIC`, `sgSYMMETRIC`, `sgFIXED`. It returns nothing; verify through the constrained status. |
| Status                    | `ISketch.GetConstrainedStatus()`                                                                                                               | 2 under, 3 fully, 4 over, 5 no solution, 6 invalid solution.                                                                                                                                                                                                                                      |
| Segment type              | `ISketchSegment.GetType()`                                                                                                                     | 0 line, 1 arc (circles too), 2 ellipse, 3 spline. Construction lines: `ConstructionGeometry`.                                                                                                                                                                                                     |
| Fillet                    | `SketchManager.CreateFillet(radius, 1)` on a selected corner point                                                                             | Adds its own radius dimensions.                                                                                                                                                                                                                                                                   |

## Features

| Feature        | Call (with the profile or entities selected)                                                                                                                                          | Key arguments                                                                                                                                                                                  |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Boss extrude   | `FeatureManager.FeatureExtrusion3(sd, flip, dir, t1, t2, d1, d2, false, false, false, false, 0, 0, false, false, false, false, merge, true, true, swStartSketchPlane, 0, false)`      | `sd` single direction (false = both, using `d2`); `dir` reverses direction 1; `t1`/`t2` `swEndCondBlind` / `swEndCondThroughAll`. 23 arguments.                                                |
| Cut extrude    | `FeatureCut4(sd, flip, dir, t1, t2, d1, d2, false, false, false, false, 0, 0, false, false, false, false, false, true, true, true, true, false, swStartSketchPlane, 0, false, false)` | `dir` true cuts along the sketch normal. A face sketch's normal points out of the body, so `false` cuts in. Toward empty space it returns null. `flip` cuts outside the profile. 27 arguments. |
| Offset plane   | select reference, `InsertRefPlane(8, distance, 0, 0, 0, 0)`                                                                                                                           | 8 = distance; add 256 to flip side. Returns the plane (cast to `IFeature`).                                                                                                                    |
| Shell          | select open faces, `IModelDoc2.InsertFeatureShell(thickness, outward)`                                                                                                                | Returns nothing: take the last feature (type `Shell`).                                                                                                                                         |
| Fillet         | select edges, `FeatureFillet3(195, r, 0, 0, 0, 0, 0, null x7)`                                                                                                                        | 195 = propagate 1 + uniform radius 2 + attach edges 64 + keep features 128.                                                                                                                    |
| Chamfer        | select edges, `InsertFeatureChamfer(0, swChamferAngleDistance, d, angle, 0, 0, 0, 0)`                                                                                                 | Angle in radians.                                                                                                                                                                              |
| Linear pattern | marks above, `FeatureLinearPattern5(n1, s1, 1, 0, flip1, false, "NULL", "NULL", false, false, false, false, false, false, true, true, false, false, 0, 0, false, false)`              | If the pattern reports an error (for example, instances off the body), delete it and retry with the direction reversed. The spacing dimension name varies (`D3` seen).                         |
| Fill pattern   | marks above, `CreateDefinition(swFmFillPattern)` as `IFillPatternFeatureData`, set every field, `CreateFeature(data)`                                                                 | `PatternLayoutType = swPatternLayoutPerforation`, `InstanceSpacing`, `LoopSpacing`, `StaggerAngle` (rad), `Margins`.                                                                           |
| Delete         | `Select2(false, 0)`, `Extension.DeleteSelection2(0)`                                                                                                                                  |                                                                                                                                                                                                |

| Separate body | `FeatureExtrusion3(..., merge=false, useFeatScope=false, useAutoSelect=false, ...)` (`cad.Extrude(..., merge: false)`) | For reference envelopes and keep-out volumes in one part. |
| Rollback | `FeatureManager.EditRollback(swMoveRollbackBarToBeforeFeature, name)`; `EditRollback(swMoveRollbackBarToEnd, "")` | Returns bool. New features are inserted at the bar. Handles taken before can disconnect. |
| Reorder | `Extension.ReorderFeature(name, target, swMoveBefore)` | Returns false for an absorbed sketch: move the feature that consumes it. |
| Edit a sketch | select the sketch feature, `EditSketch()`, select segments, `Extension.DeleteSelection2(swDelete_Absorbed)`, `SketchManager.InsertSketch(true)` | Delete equations on the doomed dimensions first. |
| Edit definition | `GetDefinition()` (e.g. `ILinearPatternFeatureData`), `AccessSelections(doc, null)`, change values, `ModifyDefinition(data, doc, null)` | `D1TotalInstances` sets a pattern count. `IExtrudeFeatureData2.FeatureScope` is settable; `ILinearPatternFeatureData.FeatureScope` is read-only. Each modification rebuilds (slow on big parts). |
| Suppression | `IFeature.IsSuppressed2(swSpecifyConfiguration, names)` (bool[]), `SetSuppression2(swUnSuppressFeature, swAllConfiguration, null)` | Check after adding features to a configured model. |

Type names from `GetTypeName2()` seen in practice: `RefPlane`, `ProfileFeature` (sketch), `Extrusion` (first boss), `ICE` (later bosses and cuts), `Shell`, `Fillet`, `LPattern`, `MateGroup`. Confirm on a known feature before relying on any other name.

## Geometry and measurement

| Data          | Call                                                                 | Layout                                                                                |
| ------------- | -------------------------------------------------------------------- | ------------------------------------------------------------------------------------- |
| Solid bodies  | `IPartDoc.GetBodies2(swSolidBody, false)`                            | object[] of IBody2                                                                    |
| Planar face   | `IFace2.Normal` (outward), `ISurface.PlaneParams`                    | `[nx, ny, nz, px, py, pz]`                                                            |
| Cylinder      | `ISurface.CylinderParams`                                            | `[px, py, pz, ax, ay, az, r]`. A hole can be split into several faces; count by axis. |
| Exact extents | `IBody2.GetExtremePoint(dx, dy, dz, out x, out y, out z)`            | `GetBodyBox()` can be loose on curved bodies.                                         |
| Edge ends     | `IEdge.GetStartVertex()` / `GetEndVertex()`, `IVertex.GetPoint()`    | Null for closed edges (full circles).                                                 |
| Volume        | `Extension.CreateMassProperty()`, `UseSystemUnits = true`, `.Volume` | m³                                                                                    |
| Body validity | `IBody2.Check3` (property)                                           | Returns an `IFaultEntity` when faults exist; no faults means valid.                   |

## Equations and configurations

| Task                 | Call                                                                                                                                                                                                        | Notes                                                                                                                                                                                               |
| -------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Manager              | `GetEquationMgr()`                                                                                                                                                                                          | Fetch again after every configuration change.                                                                                                                                                       |
| Add                  | `Add2(-1, "\"Name\" = 2mm", true)`                                                                                                                                                                          | Index, or -1 if rejected. ## Assemblies

| Task                           | Call                                                                                                                                                      | Notes                                                                                                                                                 |
| ------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| Insert                         | `IAssemblyDoc.AddComponent5(path, 0, "", false, "", x, y, z)`                                                                                             | The file must already be open. Returns the component.                                                                                                 |
| Pose                           | `IComponent2.Transform2`                                                                                                                                  | 16 values: rotation 0..8, translation 9..11 (m), scale 12. | Fix / float                    | select component, `FixComponent()` / `UnfixComponent()`                                                                                                   | The first inserted component is fixed.                                                                                                                |

| Mate                           | `AddMate5(type, align, flip, dist, distMax, distMin, gearNum, gearDen, angle, angleMax, angleMin, positioningOnly, lockRotation, widthOption, out error)` | `error` 1 = no error. `align`: 0 aligned, 1 anti-aligned, 2 closest. `cad.Mate(asm, type, align, distanceMm, a, b)` wraps it.                         |
| Entity in a component          | `IComponent2.GetCorrespondingEntity(partEntity)`; or faces of `IComponent2.GetBodies3(swSolidBody, out info)`                                             | Null when the part shows a different configuration than the component references. | Status                         | `IComponent2.GetConstrainedStatus()`                                                                                                                      | 2 under, 3 fully, 4 over. | Configuration of an occurrence | `IComponent2.ReferencedConfiguration`                                                                                                                     | Set per active assembly configuration.                                                                                                                |
