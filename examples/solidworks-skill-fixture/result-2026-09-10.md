## Failures and scope

The record contains 50 bounded attempts: 34 returned and 16 failed, including compile failures. There were no native timeouts, application kills or relaunches. API return/type assumptions, mate selections, direction and configuration suppression needed corrections. Failed hash reads initially produced invalid null-equality evidence; that evidence was excluded and a separately recorded edit trial used successful reads. Drawing-dimension import and export settings also needed corrections. A process returning successfully was never sufficient for acceptance.

The installed standard template directory lacked part/assembly templates. The worker inspected blank native resources supplied with SOLIDWORKS, copied them and saved explicit private templates. It did not open private template paths exposed by application preferences or change persistent defaults. No reproducible defect was observed in the published connector or launcher.

The trial verifies this small fixture on one installed version. It does not establish compatibility with every SOLIDWORKS release, arbitrary CAD competence, manufacturing fitness or a universal zero-interference detector. Actual geometry and saved-file checks remain necessary for every new job.
