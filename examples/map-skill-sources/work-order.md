# East work order EW-09

## Required: shift handover

Read queue.txt as UTF-8. Each nonempty line contains ID, status and title separated by vertical bars. Select only OPEN rows, retaining their order. Write handover.txt in UTF-8 with LF newlines. Its first line is Open: N, where N is the number of selected rows. Each subsequent line is ID - title. End with one newline. Do not include CLOSED rows. Check every included and excluded row against the source. Attach the checked file to the work record; then upload it to the East delivery area and retain its receipt. Local preparation and checking can proceed before delivery access is available.

## Required: bracket model

Create the bracket specified by the two-sheet drawing [sheet 1](bracket-sheet-1.svg) and [sheet 2](bracket-sheet-2.svg). Dimensions are in millimetres. The final native model is bracket.SLDPRT; also export bracket.step in STEP AP214 millimetres. Reopen the neutral export and compare the body count and every dimension with both sheets. Save both checked files, then upload them to the East delivery area and retain its receipt. Sheet 1 alone does not define the part completely.

## Optional: newsletter

Only prepare a newsletter if the workshop coordinator selects it. No newsletter has been selected for EW-09. It is not needed to complete the required September pack.
