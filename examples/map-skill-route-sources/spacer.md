# Spacer assignment

Create the spacer specified by [the complete drawing](spacer.svg). The dimensions and manufacturing notes in that original are authoritative. You may model from this drawing or follow the [training recording](https://workshop.invalid/training/spacer). The recording is an alternative teaching route.

Before modeling, complete the workstation setup. Export one STEP file named `spacer.step`. Reopen the export and check the length, width and thickness against the drawing before delivery.

Upload `spacer.step` to [the delivery form](https://workshop.invalid/deliveries/spacer) after signing in with an account authorized for this assignment. This link is the destination, not another specification. Select the file, submit it, then retain the form's receipt showing filename `spacer.step` and status `Received`. Do not require that receipt before uploading. The assignment finishes when that receipt has been checked.
