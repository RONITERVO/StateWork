# Work packets

A worker opens the focused task and gets a short visual route, one action at a time, exact instructions, an observable result, recovery instructions, prerequisites, and source excerpts. Print includes the whole route, checks, requirements, unanswered questions and reference material. Paper and screen identify the packet revision and review state.

## Acceptance contract

- A complete manual path works without an AI service, account or network: capture sources, author/revise steps, resolve questions, review, follow, record checks, export and print.
- Existing task descriptions, parent context, prerequisites and linked notes are collected with explicit coverage. A link alone never counts as having read its contents.
- Source captures are immutable, dated and attributed. Replacements preserve earlier captures. Citations resolve to captured text and an exact location; unknown/unsupported citations cannot be reviewed.
- Readiness is computed, never asserted by a model: missing fields, unanswered questions, unavailable requirements, changed context, replaced sources and absent human review are visible. No software can guarantee that an unknown real-world requirement does not exist.
- A reviewed packet has a measurable outcome, concrete actions, per-step result checks and recovery, and a final acceptance check. Completion records are versioned events; revising instructions never silently carries old checks into new instructions.
- Optional Codex assistance uses the supported locally installed CLI and its own saved sign-in. It receives an explicit source bundle, returns a validated draft and cannot approve it or modify work. No credentials are extracted or embedded. Cancellation, failures and account limits leave manual work intact.
- External assistants and company adapters can obtain context and submit source captures and drafts through documented SDK, REST and MCP contracts. Authenticated browser content requires an authorized connector or an explicit local capture; the app does not pretend to inherit the Codex desktop browser session.
- Screen, keyboard, phone, print and the spatial office use the same packet. Short step labels and shapes show progress; details and references remain immediately available.
- Fictional fixtures cover the complete workflow, missing/conflicting evidence, stale revisions, retries, roles, malicious source strings, print layout, mobile and immersive entry points. Personal content stays in the private database.
